# Living Room Lights

A phone-first web app for controlling Govee lamps through the Govee cloud API — room themes, zones, scenes and saved looks.

Open the site, paste your own Govee API key (Govee Home app → Profile → Settings → Apply for API Key), and add it to your Home Screen. The key is stored only in your browser and is sent only to Govee.

`config.json` holds the room layout, zones and themes.
